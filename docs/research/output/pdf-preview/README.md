# Uniform PDF layout preview

The fixed-template renderer is now reused by the server-only [persisted output pipeline](../../../output-pipeline.md). These files also retain the standalone synthetic/sample previews. Runtime generation reads a pinned validated D1 snapshot and stores the generated PDF in private R2. The executable engine remains pending.

This is a research prototype for reviewing the report's appearance. It is not connected to application routes, storage, an engine result or the confidence gate. Every page is labeled STUB and identifies the figures as illustrative.

The original synthetic preview below remains a layout reference. A separate [engine-sample PDF](sample-engine-report.pdf), generated by [engine-report.mjs](engine-report.mjs) from the supplied PR #123 result, is now downloadable in the workspace Report view. It preserves the sample values and is still an offline STUB export; live generation and storage are not connected. See the [consumer notes](../engine-samples.md).

[Open the eight-page PDF preview](valueiq-report-preview.pdf). This project copy is retained for review; temporary-directory links are not required. The embedded fonts' [license](FONT-LICENSE.txt) accompanies the PDF.

[renderer.mjs](renderer.mjs) provides a consistent A4 grid, static regular/bold fonts, shared headers/footers, metric cards, wrapped tables with right-aligned currency, repeated table headings, row pagination and section/content grouping. It draws vector waterfall, driver-contribution, cash-flow and discount-rate sensitivity charts. [fixture.json](fixture.json) supplies the values, display labels, chart endpoints and axis ticks; the renderer only calculates layout geometry.

The prototype rejects unsupported font glyphs rather than silently printing a missing-character box. Oversized table rows fail visibly; splitting a single row longer than a page remains outside this preview.

## Reproduce

Use a temporary directory for preview dependencies and fonts; the application needs no new dependency or binding. The existing spike directory can be reused:

```sh
npm install --prefix /tmp/valueiq-output-pdf-spike --no-audit --no-fund pdf-lib@1.17.1 @pdf-lib/fontkit@1.1.1

curl -fL https://raw.githubusercontent.com/notofonts/noto-fonts/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf -o /tmp/valueiq-output-pdf-spike/font.ttf
curl -fL https://raw.githubusercontent.com/notofonts/noto-fonts/main/hinted/ttf/NotoSans/NotoSans-Bold.ttf -o /tmp/valueiq-output-pdf-spike/font-bold.ttf
curl -fL https://raw.githubusercontent.com/notofonts/noto-fonts/main/LICENSE -o /tmp/valueiq-output-pdf-spike/FONT-LICENSE.txt

node docs/research/output/pdf-preview/generate.mjs --runtime /tmp/valueiq-output-pdf-spike --fonts /tmp/valueiq-output-pdf-spike --output /tmp/valueiq-output-pdf-spike/valueiq-report-preview-v2.pdf
node docs/research/output/pdf-preview/generate.mjs --runtime /tmp/valueiq-output-pdf-spike --fonts /tmp/valueiq-output-pdf-spike --output /tmp/valueiq-output-pdf-spike/uniform-stress.pdf --stress
```

[generate.mjs](generate.mjs) loads libraries from that temporary runtime directory and writes the PDF plus a JSON record of block bounds. Retain the font license with the generated artifacts. The same renderer was also exercised through the isolated local Worker described in the [research record](../README.md#pdf-compatibility-spike).

## Observed verification · November 5, 2026

- Standard preview: eight pages. Long-table stress preview: 13 pages, including 90 additional audit rows and a deliberately long wrapped row.
- All pages retain STUB, confidence-status and page-number labels. All ten report sections, the four chart titles and supplied financial labels extract from the PDF.
- The renderer's body-bound checks pass. Continued audit tables repeat their column headings and preserve the final row. The standard eight pages were rasterized and visually reviewed; missing minus glyphs were corrected to the font-supported hyphen-minus.
- The prototype is a visual reference only. Engine contract integration, configurable report structure, storage/access, arbitrary-language coverage and production resource limits remain unfinished.
