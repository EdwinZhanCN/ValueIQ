# SOURCES.md: where our calculation research comes from (register, started Nov 4, 2026)

Purpose: one honest list of every source behind ValueIQ's calculation, haircut, confidence, and report design. It feeds (1) the writeup, (2) a "Sources and method" page on the website, (3) the final presentation. Rule: **log a source here the moment we use it, with its status.** Do not upgrade a status without actually opening the document.

## Status legend (show these badges on the website)

| Badge                | Meaning                                                                                 |
| -------------------- | --------------------------------------------------------------------------------------- |
| **READ**             | A team member or agent opened the primary document and read the relevant text.          |
| **READ (secondary)** | Opened a secondary write-up (article, summary, explainer) but not the primary document. |
| **FOUND**            | We know the document exists and where, but have not opened it.                          |
| **SNIPPET**          | We only saw it in a search-result summary. Treat as a lead, not evidence.               |
| **NOT ACCESSIBLE**   | Tried and failed (403, paywall, binary).                                                |
| **TEAM JUDGMENT**    | A number or rule we chose; it is bracketed by sources but not stated by any.            |
