# Core beliefs

- Assessment inputs need evidence and explicit assumptions. Missing facts produce follow-up questions, not invented monetary results.
- The model chooses questions and tools; deterministic TypeScript owns arithmetic. A capacity estimate or expected avoided loss is not guaranteed cash savings.
- Conversations are working context. Durable application records remain useful independently of any particular agent session.
- Keep one repository and one Cloudflare application until a measured need justifies another service.
- Make incomplete behavior visible. Nothing unconnected or scripted may be presented as a functioning assessment.

Authentication, billing, dashboards, complex state machines, multi-agent orchestration, RAG, vectors, ingestion, MCP integrations, Redis, queues, and additional backends stay out of scope until a concrete product need justifies them.
